# Sypha CLI

The AI coding agent for your terminal. Describe what you want: Sypha reads your project, writes and edits code, runs commands and explains what it did.

## Install

```bash
npm install -g @sypha-ai/cli
```

```bash
conda install -c sypha_ai sypha-cli
```

Upgrade with `sypha upgrade`.

## Get started

```bash
sypha                                      # open Sypha in your project (sign in on first run)
sypha run "add tests for the login form"    # one task, no screen
```

## Highlights

- **Sypha Auto Mode** Request sent to India hosted model.
- **Agents** for every job: Code, Plan, Ask, Debug and Orchestrator, with subagents you can steer while they run.
- **Any model**: the Sypha Gateway, or your own providers such as Anthropic, OpenAI, OpenAI Codex (ChatGPT sign-in), Google and OpenRouter.
- **Extend it** with MCP servers, skills, custom commands and workflows.
- **Teams**: admins choose providers, models and permissions from the Sypha dashboard.
